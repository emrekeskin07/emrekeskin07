### What I'm building

**[TEK Finance](https://tekfinanceapp.com)** — a personal finance platform for retail investors in Turkey (BIST, US stocks, gold/silver, funds). Built solo, from idea to production.

- React 19 · Node.js / Express · Supabase (PostgreSQL + Row Level Security)
- Frontend on Vercel, backend on Render, domain on Cloudflare DNS
- Subscription payments with signed webhooks, plan limits enforced on the server
- Returns adjusted for inflation (TÜİK & ENAG) to show real purchasing-power change
- Market data services (Yahoo Finance, BilancoVeri) with caching
- An AI assistant (Gemini) that answers using the user's own portfolio data
